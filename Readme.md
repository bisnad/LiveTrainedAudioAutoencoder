# ALTA - Audio Live-Trained Autoencoder
### Overview

The “Audio Live-Trained Autoencoder” (*ALTA*) employs a custom variational audio autoencoder that is simple enough to be trained very quickly (within minutes) on tiny amounts of audio material (seconds of audio). Accordingly, *ALTA* can generate audio in real time while being trained simultaneously. This opens up the possibility of making the training process of *ALTA* a central interactive element in a musical performance. In this scenario, a performer can use *ALTA* as a digital musical instrument whose acoustic characteristics continuously change in direct response to the manipulation of the training process.

The main possibilities for manipulating the training process include:

- Manipulating the training set by adding and removing audio files or incorporating live input from a microphone.

- Manipulating the overall training settings that affect how quickly the autoencoder learns and forgets.

- Manipulating which loss functions are employed and how strongly they are weighted during the learning process.

*ALTA* is currently implemented only in Python and is still in its early prototyping stage, both in terms of functionality and user friendliness. However, it is sufficiently usable and stable to allow composers and musicians to experiment with it and provide feedback. This feedback will guide the further development. The long-term goal is to implement and release *ALTA* as a software component that can easily be integrated into popular programming environments for computer music, such as *Max/MSP* and *SuperCollider*.

### Repository Structure

The repository contents are as follows:

- `Data/audio` contains a small set of example audio files that can be used as a starting point for training the autoencoder.
- `Data/configs` contains an example configuration for a user interface.
- `Data/exports` contains audio generated by the autoencoder and exported as audio files.
- `Data/sessions` contains example logs of previous training and interface manipulation sessions that can be replayed.
- `Data/weights` contains the autoencoder weights from previous training runs.
- `Docs` contains instructions for installing the environment required to run the autoencoder, along with a description of the user interface, and a general introduction to autoencoders.
- `Installers` contains project files and scripts for preparing the installation.
- `Software/Autoencoder` contains the source code for *ALTA* and convenience scripts for running it.
